# 🤖 AI দিয়ে Code Review

AI (Artificial Intelligence) ব্যবহার করে নিজের লেখা JavaScript Code Review করা যায়।

(AI ব্যবহার করে কোডের ভুল, পুরনো Syntax এবং ভালো Practice সহজে খুঁজে বের করা যায়।)

### Example

### Before (Old ES5)

```javascript
var greet = function(name){
    return "Hi " + name;
}
```

### After (Modern ES6)

```javascript
const greet = (name) => `Hi ${name}`;
```

# ⚡ One Minute Revision

- `let` এবং `const` ব্যবহার করো।
- Template Literal ব্যবহার করো।
- Arrow Function লিখতে শিখো।
- Spread Operator দিয়ে Copy/Merge করো।
- Destructuring দিয়ে Value বের করো।
- Object.keys(), values(), entries() জানো।
- Object.seal() ও Object.freeze() এর পার্থক্য জানো।
- Nested Object Access করতে পারো।
- Optional Chaining দিয়ে Error এড়াও।
- Object Loop করার জন্য `for...in`, `Object.keys()` এবং `Object.entries()` ব্যবহার করো।
- AI-কে Helper হিসেবে ব্যবহার করো, Solution Machine হিসেবে নয়।
